Title

Number Guessing Game using Python

Aim

To develop a simple number guessing game using Python programming.

Description

This program generates a random number between 1 and 100.
The user has to guess the number.
The program gives hints like Too High or Too Low until the correct number is guessed.

Algorithm:


Start

Import random module

Generate a random number between 1 and 100

Initialize attempts to 0

Ask the user to enter a number

Compare the guessed number with the generated number

Display “Too High” or “Too Low” accordingly

Repeat steps 5–7 until the guess is correct

Display total number of attempts

Stop


Tools / Language Used:

Python

Random module
