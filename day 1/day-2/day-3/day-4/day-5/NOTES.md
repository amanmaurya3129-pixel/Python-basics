Contact Book (Python CLI Project)

Project Overview:-
The Contact Book is a beginner-level Python project that allows users to:
Add new contacts
View all saved contacts
Search for a specific contact
Exit the program
This project is menu-driven and runs in the command-line interface (CLI).

 Objective:-
The main goal of this project is to practice:
Python dictionaries
Loops (while loop)
Conditional statements (if-elif-else)
User input handling
Basic CRUD operations

🛠 Technologies Used
Python 3
No external libraries require  

How It Works:-
1️.Add Contact
User enters name and phone number.
Data is stored in a Python dictionary.
Format:
contacts[name] = phone

2️.View Contacts
Displays all saved contacts.
If no contacts exist, shows a message.

3️.Search Contact
User enters a name.
Program checks if name exists in dictionary.
Displays phone number if found.

4️.Exit
Ends the program safely.



How to Run the Project:-
Install Python (if not installed).
Open terminal in project folder.
Run:
python main.py
