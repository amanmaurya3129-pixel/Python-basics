Simple Calculator in Python
📌 Description

This is a Simple Calculator program written in Python.
It performs basic arithmetic operations using a menu-driven approach and runs continuously until the user chooses to exit.

✨ Features

Addition

Subtraction

Multiplication

Division

Handles division by zero error

Uses while loop for repeated execution

Takes user input from the console



🛠 Concepts Used

print() and input()

while True loop

if conditions

Type conversion using int()

Basic error handling



▶ How to Run the Program

Make sure Python is installed on your system

Open terminal / command prompt

Run the file using:

python calculator.py
